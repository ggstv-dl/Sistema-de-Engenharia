### Bloqueio para fechar F1

O serviço Docker negou acesso ao socket `/var/run/docker.sock`, inclusive na tentativa fora do sandbox. Por isso, build da imagem e subida de um clone limpo com Compose ainda não foram validados. O teste funcional alternativo usou PostgreSQL 17 e Node.js 24 disponíveis; a imagem usa PostgreSQL 16 e Node.js 22. Isso não substitui a validação final dos containers.

Em um clone novo com acesso ao Docker, seguir a seção 6.1 do README e executar também `docker compose exec api npm run check`. Registrar o resultado aqui antes de marcar F1 como concluído. Não usar um volume de banco preexistente para comprovar instalação limpa.
