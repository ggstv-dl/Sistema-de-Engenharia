## F1 — ambiente reproduzível

Inicialmente, o grupo configurou o `.env.example` com conexão autenticada e variáveis coerentes e ajustou o `.gitignore` para excluir arquivos locais. Em seguida, preparou o Dockerfile, o `.dockerignore` e o Compose com banco persistente, verificações de disponibilidade e aplicação das migrations antes da inicialização da API. O grupo também alinhou as regras de `.clinerules` ao JavaScript/CommonJS e aos contratos em português existentes. Por fim, documentou o procedimento no README e incluiu o teste de fluxo HTTP em `scripts/smoke.js`.

### Verificações realizadas pelo grupo

Após preparar o ambiente, o grupo executou as verificações abaixo e registrou os resultados:

- `docker compose --env-file .env.example config --quiet`: passou.
- `npm run check`: passou.
- `prisma validate`: passou.
- Banco PostgreSQL 17 temporário vazio: `prisma migrate deploy` aplicou a migration inicial e `prisma generate` gerou o client.
- Seed executado duas vezes: 2 engenheiros, 2 clientes, 2 projetos e 2 diários ao final; sem duplicação desses registros.
- `SMOKE_BASE_URL=http://127.0.0.1:3300 node scripts/smoke.js`: passou health 200, dashboard sem token 401, senha inválida 401, login 200 e dashboard autenticado 200 com obra e diários do seed.

### Bloqueio para fechar F1

Em 26/10, o grupo encontrou uma restrição de acesso ao socket `/var/run/docker.sock`, inclusive na tentativa de execução fora do ambiente restrito. Por esse motivo, não conseguiu validar a construção da imagem nem a inicialização de um clone limpo com Compose naquela data. Para verificar o funcionamento disponível, utilizou PostgreSQL 17 e Node.js 24; as imagens do projeto utilizavam PostgreSQL 16 e Node.js 22. O grupo registrou que essa verificação alternativa não substituía a validação dos containers.

O grupo deixou como pendência a validação em um clone novo com acesso ao Docker, conforme o procedimento de instalação do README, incluindo `docker compose exec api npm run check`. A conclusão de F1 depende do registro desse resultado, sem utilizar um volume de banco preexistente como comprovação de instalação limpa.
